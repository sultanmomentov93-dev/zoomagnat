# ЗооМагнат — стартовый MVP для Telegram Mini App

Это первый игровой прототип: Telegram-бот открывает мини-приложение, игрок получает 250 игровых монет, покупает животных, а животные приносят пассивный игровой доход. Данные хранятся на сервере в SQLite.

## Важно до запуска
- Игровые монеты в этой версии НЕ являются криптовалютой и НЕ обмениваются на деньги.
- Вывод, обмен, депозит и покупка монет отключены. Это намеренно: сначала проверяем игру и экономику.
- Для реальных выплат понадобятся проверенный источник выручки, опубликованные правила, защита от накруток, налоговая/правовая проверка и отдельный платёжный процесс.
- Telegram `initData` проверяется сервером с помощью токена бота. Не доверяйте `user_id`, присланному браузером.
- Бесплатные тарифы хостинга могут засыпать, а локальная файловая база может не переживать перезапуск/переразмещение. Для публичного теста используйте постоянный диск или управляемую PostgreSQL.

## Что внутри
- `bot.py` — Telegram-бот с кнопкой открытия Mini App.
- `server.py` — FastAPI API, проверка Telegram initData, SQLite, покупки и игровой доход.
- `static/index.html` — интерфейс для телефона.
- `render.yaml` — пример конфигурации Render.

## Запуск с Android
Самый простой путь — через GitHub и Render. Всё можно сделать в браузере телефона.

### Шаг 1. Создай бота
1. В Telegram открой `@BotFather`.
2. Отправь `/newbot`, выбери имя и username.
3. Скопируй токен. Не публикуй его в GitHub и никому не отправляй.
4. Сохрани токен временно в надёжном месте.

### Шаг 2. Загрузи файлы на GitHub
1. Открой https://github.com и создай новый репозиторий `zoomagnat`.
2. Распакуй архив на телефоне.
3. Через сайт GitHub выбери Add file → Upload files.
4. Загрузи `bot.py`, `server.py`, `requirements.txt`, `render.yaml`, `README_RU.md` и папку `static` с `index.html`.
5. Не добавляй токен бота в файлы репозитория.

### Шаг 3. Разверни API на Render
1. Открой https://render.com и войди через GitHub.
2. Создай Web Service из репозитория.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn server:app --host 0.0.0.0 --port $PORT`
5. В Environment добавь:
   - `BOT_TOKEN` = токен от BotFather
   - `DATABASE_PATH` = `/var/data/zoomagnat.db` (для постоянной базы потребуется подключить диск; если диск недоступен на бесплатном тарифе, временно используй `zoomagnat.db`, но данные могут сброситься)
6. После деплоя скопируй HTTPS-адрес сервиса, например `https://имя-сервиса.onrender.com`.
7. Проверь `https://имя-сервиса.onrender.com/api/health` — должен появиться `{"ok":true,...}`.
8. В переменной `WEBAPP_URL` для бота используй корневой HTTPS-адрес сервиса.

### Шаг 4. Запусти Telegram-бота
Нужно запустить `bot.py` как отдельный Background Worker или отдельный сервис на Render:
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Environment: `BOT_TOKEN` и `WEBAPP_URL` с адресом API.
- Не запускай одновременно два экземпляра polling-бота с одним токеном.

### Шаг 5. Проверь
1. Открой бота и нажми `/start`.
2. Нажми «Открыть ЗооМагнат».
3. Проверь начальные 250 монет и покупку кролика.
4. Закрой и открой игру повторно — прогресс должен остаться, пока база не потеряна.
5. Если API сообщает «Открой игру через Telegram», убедись, что ты открыл приложение кнопкой из бота, а не напрямую в браузере.

## Экономика MVP
- Начальный баланс: 250 монет.
- Кролик: цена 50, доход 2 монеты/мин.
- Лиса: цена 180, доход 7 монет/мин.
- Олень: цена 600, доход 22 монеты/мин.
- Лев: цена 1800, доход 70 монет/мин.
- Доход начисляется максимум за 8 часов отсутствия, чтобы офлайн-доход не рос бесконечно.
- Цены/доходы — тестовые значения, их нужно балансировать по реальным данным активности.

## Честная модель наград — будущий этап
Не обещайте фиксированный обмен игровых монет на криптовалюту, пока нет реальной выручки и бюджета выплат. Безопаснее:
1. Зарабатывать на рекламе, добровольных покупках и косметических предметах.
2. Публиковать сумму реально выделенного фонда наград за период.
3. Устанавливать правила начисления, лимиты, антифрод и минимальную выплату.
4. Платить только из уже полученной выручки, за вычетом возвратов, налогов, комиссий и резерва.
5. Не финансировать старые выплаты депозитами новых игроков.
6. Перед запуском реальных выплат проверить местные правила по криптоактивам, рекламе, защите потребителей и налогам.

## Что не реализовано
- Реальные деньги/криптовалюта, обмен, вывод и подключение кошелька.
- Антибот/антифрод и модераторская панель.
- Переход на PostgreSQL и резервное копирование.
- Реферальная программа, задания и рекламная сеть.
